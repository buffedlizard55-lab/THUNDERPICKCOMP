Core values

Maximize P(Win) — every decision weighs tradeoffs and picks the path that maximizes this project's chance of becoming a genuinely useful, trustworthy daily hub.

Own the Outcome — we own results end to end. Gaps are stated plainly with a plan to close them; failures surface visibly instead of degrading silently into invented data.

Verification rules (non-negotiable)

  1. No hallucinations. Teams, rosters, odds, prices, results, stats, dates — if it can't be checked against a source, it's unknown/TBD.
  2. Claim by claim. Every material statement links to the source it was checked against, with a retrieval timestamp. A search snippet is not verification.
  3. Primary sources first: organizer releases, teams/players, Valve, exchange APIs — then HLTV/Liquipedia structured records, then reputable press with attribution.
  4. Fact vs analysis. Verified facts, calculations, model heuristics and simulated outputs are labeled as such. Strategy theses are testable rules, not punditry.
  5. Free public sources only. No paid API or subscription. Source terms, rate limits and attribution requirements are respected.
  6. Fail visibly. Missing feeds, stale prices and conflicts are shown as flags — never smoothed over.

Settlement & reproducibility

  • Leaderboard math: profit = payout − stake; win → stake × decimal_odds; loss → 0; void → stake. Bankroll = start + Σ profit. Recomputed live from data/ledger.json on the Leaderboard page.
  • Prediction shares (0–1, settle $1/$0) convert via decimal_odds = 1 / share_price; raw price + venue are always kept.
  • Settlement requires the market's own rule plus an HLTV result cross-checked on Liquipedia. Conflicts block settlement.
  • scripts/validate.py re-checks schemas, provenance, references and all money math on every change (CI).
