How a price enters this project

  1. Find: query the free public endpoints above for TWC 2026 markets (match-winner, map, outright).
  2. Capture: record venue, ticker/market id, selection, price, volume if shown, and observed_utc. Screenshot-equivalent: the API response is the receipt.
  3. Freeze: prices are append-only history — never overwritten. Stale prices are flagged, not deleted.
  4. Settle: outcomes need the market's own settlement rule plus an HLTV result cross-checked on Liquipedia. Any conflict blocks settlement and raises a flag.

Why no sportsbook odds yet?

Traditional esports books (including Thunderpick's own odds pages) have no documented free public API, and their terms generally forbid scraping. We will only add a sportsbook line if it can be captured from a freely accessible page in a way that respects the site's terms — and each line still needs its URL + timestamp. Until then, prediction-market APIs are the primary price path because they are explicitly public.
