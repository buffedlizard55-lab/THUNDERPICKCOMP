Ledger schema (what each future entry carries)

FieldMeaning
entry_id / username / match_idUnique bet id, simulated user, and the match record it belongs to.
market / selectionE.g. match-winner / map-winner / outright, and the side taken.
decimal_odds / stakePrice at capture and units risked. Prediction shares keep raw price + venue too.
placed_utc / price_sourceWhen the price was observed; venue + ticker/market id so anyone can re-check.
settlement.ruleThe market's own settlement rule, quoted or linked — a result alone never settles a bet.
settlement.result / settled_utcwin / loss / void / pending, and when it was settled.
payout / profitComputed: win → stake × odds; loss → 0; void → stake. profit = payout − stake.

Validation: scripts/validate.py recomputes every payout and fails the build on any mismatch, missing source, or reference to an unknown match/user.

THUNDERPICKCOMP — all competition activity is simulated (no real money). Facts link to public sources; missing data is labeled unknown/TBD.
