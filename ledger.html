Audit trail: what each paper decision must include

FieldMeaning
entry_id / username / match_idImmutable paper decision ID, simulated username, and a Finals match or the explicit tournament-winner reference (not a fixture).
market / selectionThe market’s exact question and chosen outcome; a Yes contract is distinct from a No contract.
decimal_odds / stakeGross 1 / raw best ask and exact simulated stake. The first-party raw ask and displayed top-of-book size are retained.
placed_utc / price_sourcePaper decision and quote receipt time; venue, market ID, quote ID and original API URL. Reopening a live URL later will not reproduce its past book.
settlement.ruleFull first-party resolution rule captured with the ask; the outcome cannot be assumed from a match score alone.
settlement.result / settled_utcpending until independently checked; later win / loss / void / partial only with venue resolution and independently verified tournament outcome.
payout / profitNull while pending. Gross win → stake / raw ask, loss → 0, verified void → stake; a 50/50 market payout is not necessarily a void. Fees/slippage excluded.

Validation: scripts/validate.py cross-checks each decision with its preserved quote ID, venue, size and time, and recomputes settled gross payout. Independent result/settlement journaling is not yet implemented, so all created positions remain pending. View source receipts.

THUNDERPICKCOMP — all competition activity is simulated (no real money). Facts link to public sources; missing data is labeled unknown/TBD.
